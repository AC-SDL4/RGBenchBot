# Datasets

Each experiment measures dispensing repeatability across 24 wells (4 groups × 6 replicates).
Each well is imaged 6 times; color is extracted in RGB, LAB, and HSV.
**Measurement uncertainty** = camera noise within a well. **Process uncertainty** = dispensing variability between replicate wells. Process noise dominates by ~27–32×.

## LoD / Composition Uncertainty Analysis (`lod_analysis/`)

Scripts are in `output/color_matching_workflow/analysis/`. Run in this order:
1. `combined_best_mar13_lod.py` — pools BEST + Mar13 (48 wells), fits sensitivity matrix, computes per-channel camera noise
2. `channel_set_lod.py` — computes 3×3 composition uncertainty table (camera + practical) for RGB, LAB, HSV

**Key result** (practical / process noise):

| Colour space | Red (mL) | Yellow (mL) | Blue (mL) |
|---|---|---|---|
| RGB | 0.071 | 0.078 | 0.033 |
| CIELAB | 0.049 | 0.063 | 0.040 |
| HSV | 0.190 | 0.257 | 0.072 |

Values are 1σ composition uncertainties: √Cov(v̂)_jj from the GLS estimator covariance (S^T Σ^{-1} S)^+, where Σ contains between-well process variance per channel.

| File | What it contains |
|---|---|
| `combined_raw.csv` | Pooled 288-row dataset (48 wells × 6 images, raw RGB/LAB/HSV + dye volumes) |
| `composition_map.csv` | The 8 distinct dye compositions tested |
| `sensitivity_coefficients.csv` | 3×3 sensitivity matrix S (channel units per mL, per dye) |
| `lod_summary.csv` | Per-channel camera-noise LoD (9 channels × 3 dyes) — input to channel_set_lod.py |
| `channel_set_lod.csv` | **Main paper result** — composition uncertainty per colorspace per dye, camera + practical |
| `rep1_effect.csv` | Rep-1 auto-exposure inflation factor per channel (informational) |
| `lod_heatmap.png` | Per-channel LoD heatmap (all reps vs excl rep1) |
| `lod_ranking.png` | Per-channel LoD bar chart ranked per dye |
| `channel_set_lod.png` | Multivariate uncertainty bar chart (camera vs practical, RGB/LAB/HSV) |
